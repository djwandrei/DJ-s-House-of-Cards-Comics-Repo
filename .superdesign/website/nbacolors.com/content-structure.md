# NBA Colors

## Business Context
- **Type/Industry:** Reference / utility site for sports design
- **What they do:** Publish official NBA team color codes in Hex, Pantone, RGB, CMYK formats
- **Target audience:** Designers, developers, branding professionals, NBA fans
- **Page goal:** Enable users to search and browse all 30 NBA team colors; discover teams via color palettes

# Page Layout & Structure

### Header / Navigation
Static horizontal nav. Left: "NBA COLOR CODES" (logotype, links to index). Right: 3 nav links (About, Teams, Contact) in dark gray text. Below: thin near-black horizontal rule (full-width divider).

### Hero
Tall search container with near-black border, rounded corners. Left: search icon. Center: textbox "Search for NBA colors..." (placeholder text). Below textbox: help text in muted gray "Ex: LA Lakers, Purple, Gold, etc." No decorative elements; functional, high-contrast layout.

### Team Grid ×30
- **Purpose:** Browsable index of all 30 NBA teams, sortable by color or name.
- **Layout:** 2-column uniform grid. Each row: 2–3 circular color swatches (2–4 circles per team, overlapping slightly) + underlined team name link. Left column and right column are equally wide. No background color variation. Rows stack vertically with consistent vertical rhythm.

### Footer Divider
Near-black horizontal rule (full-width, matching header divider).

### Footer
4 columns. **Left column (nav):** 4 stacked links (About, Teams, Retro, Contact) in dark gray. **Center-left:** 2 stacked links (Twitter, Instagram) in dark gray. **Right:** "Built by Toni Gemayel" + clickable orange avatar circle. Footer text is small, dark gray on near-black background.

**Notable patterns:** 
- Uniform 2-column grid for team links (no alternating layouts).
- Color swatches are the primary visual element; no secondary illustrations or badges.
- Navigation and footer use identical link styling (underlined, dark gray).
- No sticky elements; linear scroll from header through grid to footer.
