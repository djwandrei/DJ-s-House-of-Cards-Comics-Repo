# Approved fan-suite extension — September 7, 2026

The user approved implementing the Lineup Lab direction throughout the fan
tools and requested this five-page canvas set plus a GitHub/cPanel release.
This is a sibling flow of the selected Lineup Lab draft, not a new brand.

## Shared design contract

For these pages, the approved Lineup Lab system supersedes the older storefront
font/grass direction in design-system.md. Use Manrope 400/700 for body and menus,
Barlow Condensed 700 for display headings/numerals, 12–16px corners, navy canvas,
DJHC gold/blue accents, concise sections and comfortable 44px controls. Preserve
the exact DJ logo/script identity. Dark is default; Light remains a preference.
Use the tokens from basketball-palettes.mjs, not arbitrary additional colors.
Only an actual selected supported team changes palette. No invented selector
that changes the game board. The hub, workshop, and card lookup retain DJHC.

Common navigation: Fan Tools, Lineup Lab, Fix the Five, Draft Night, Player &
Cards, Workshop. Indicate the current destination with text and an accent rule.
Finite 160–280ms transitions, intentional emblem bounce, reduced-motion bypass.
No timers, flashing, constant particle loops, fake scores, fake live counts,
invented player stats, team logos, NBA marks, or official-affiliation claims.

## Confirmed pages

- Fan Tools homepage: short choose-your-next-play hero; existing Live filters
  and suggestion action; four live entries plus Lineup DNA as Lab explanation;
  roadmap collapsed and explicitly Planned/Research. No new game promotion.
- Fix the Five: one legal swap, five daily source-labeled boards; selected,
  confirm, reveal progression. Source unavailable is an honest main state.
- Draft Night: five picks, compact progress and chosen-player slots; inspect,
  confirm, advance, review. Source unavailable stays honest, never synthetic.
- Player & Card Matchups: player search first, exact verified mapping results,
  empty and ambiguous states; concise how-matches-work disclosure.
- Workshop: planned framework chooser, local setup, stage preview and roadmap;
  prominent unfinished/scoring-disconnected labels, never a fake playable game.

Reuse actual public Brand Asset URLs from the project: DJ logo, Lineup Lab,
Fix the Five and Draft Night badges, Manrope and Barlow fonts. Use the uploaded

Use exact supplied logos in every logo position, never initials/emoji or a
